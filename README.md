# Ардақ ұстазбен бірге: Математикалық паспорт — сынақ нұсқасы

Бұл архив бастапқы GitHub кодына негізделген. **Тікелей Render/GitHub-қа жарияламаңыз**: әуелі тестілеу қажет.

## Жергілікті іске қосу

```bash
export TEACHER_PASSWORD='ӨЗІҢІЗДІҢ_КҮШТІ_ҚҰПИЯСӨЗІҢІЗ'
python server.py
```

Браузер: http://localhost:8766

Қосылғаны: III бағыттың Word жинағынан 360 сұрақ, 4 сатылы тьютор, сынып әрпі мен оқу жылы, мұғалім сүзгілері. Сұрақтар **редакторлық математикалық QA-дан толық өткен жоқ**. Қазіргі мұғалім кабинеті бір ортақ құпиясөзбен жұмыс істейді: **көп мектепке ашуға қауіпсіз емес**. Жеке мұғалім тіркеуі, сынып кодтары, автор кабинеті, оқушыларға қатысты қолжетімділік және деректерді тұрақты сақтау әлі жасалуы тиіс. Бастапқы 1 және 2 бағыттағы генераторлар өзгеріссіз қалған, олардың сапасын бөлек тексеру қажет.

`DATABASE_PATH` айнымалысы арқылы тұрақты диск жолын көрсетуге болады. Render-дегі диск конфигурациясын бөлек орнату қажет.
